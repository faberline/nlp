# CPU CLI distribution notices

The `licenses` directory contains the exact notices tracked with the embedded multilingual lexicon and Mamba-derived code. The dictionary is compiled into the executable. Formal model weights are not included.

The English lexicon uses the legacy Princeton WordNet 3.1 input. The tracked WordNet notice is the BSD-style notice for that input. Open English WordNet 2023 is a separate work and is not the input identified here.

The package includes the dependency license files present in the locked Cargo metadata closure and a receipt listing its limits. Some upstream packages do not include a notice file in their crate archive. The source-lexicon receipt in the repository identifies the embedded data inputs. The Cargo notice receipt describes the dependency closure; it does not establish source provenance for every embedded input. This notice does not assert that all distribution obligations have been established.
