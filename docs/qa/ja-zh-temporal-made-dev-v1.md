# 時間端點開發控制

本提案新增五個 N5 近似的開發句。它們都是肯定的禮貌非過去式陳述句。

## 持續到時間端點

TMD-N5-01 使用時鐘時間「六時まで」。TMD-N5-02 使用星期日這個非時鐘端點。兩句使用相同的行動者、活動和受詞。兩句都表示學日文的活動持續到端點。它們不表示學習在端點前完成。

## 最晚期限

TMD-N5-03 使用時鐘期限「六時までに」。TMD-N5-04 使用非時鐘期限「日曜日までに」。兩句都表示最晚可以在指定時間完成，或提早完成。兩句不表示信已經寫完。

## 期限和事件時間對照

TMD-N5-03 和 TMD-N5-05 使用相同行動者、時間、物件和動詞形式。日文唯一差別是期限句多了「まで」。

- TMD-N5-03 的「六時までに」表示最晚期限。
- TMD-N5-05 的「六時に」表示寫信事件發生的時間。

事件時間句沒有表示信在六點寫完，也沒有表示寫信活動持續到六點。

## 重用的控制

jz001 的「駅まで」表示乘車路徑的空間端點。它也包含「毎朝」和「バスで」，不是時間期限控制。CLOCK-C12 使用「午後二時に」表示時間點，也使用「教室に」表示移動目標。CLOCK-C13 只有移動目標「教室に」。這些控制不替代新的時間端點句。

## 限制

本組句子不證明所有「まで」和「までに」都能正確處理。實際分析路徑和引擎結果未知。獨立檢查者須在採納前檢查語意與台灣中文自然度。
