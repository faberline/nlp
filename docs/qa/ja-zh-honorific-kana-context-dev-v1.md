# 平假名接「さん」的前文對照

兩題取自 #196 的第一方原創草案，採 MIT 授權。原文沿用草案。撰題時的主線是 `adf9f9b1a4a2c873f352fec37e1444c742e5587b`。檔案樹是 `54ddbadfbf4cc9cfcaec45bd076ef1a7b118a7b7`。 [公開草案](https://github.com/faberline/nlp/issues/196)

| 題號 | 前文提供的意思 | 末句要保留的意思 |
| --- | --- | --- |
| HKC-N5-01 | 「ことり」是說話者朋友的綽號。 | 這位朋友在這裡。前後沿用同一個綽號。 |
| HKC-N5-02 | 故事中的「ことり」是普通名詞，指體型小的鳥。 | 小鳥在這裡。 |

兩題的末句逐字相同。每題保留前文引號和末句的「這裡」。人物題可保留假名或採中性轉寫。原文未交代性別。兩題都不增加姓名漢字、性別或職稱。動物題保留故事背景、小鳥的釋義和牠所在的位置。

HS-03 和 HS-04 已涵蓋原文明示的姓名。HS-11 和 HB-L01 涵蓋另外兩種詞界。這一組只檢查能否用前文區分綽號和普通名詞。缺少前文時，「さん」或分詞結果不足以確定指稱。 [既有分詞證據](https://github.com/faberline/nlp/issues/91#issuecomment-6967254170) · [詞界對照採納](https://github.com/faberline/nlp/issues/140#issuecomment-6984008522)

兩題都用原始 UTF-8 全文、純 CPU、內建詞庫和空術語表。目標是 `zh-Hant`。原文與 335 道已採納請求比較。原始位元及 NFKC 正規化後移除空白的比較均無重複。
