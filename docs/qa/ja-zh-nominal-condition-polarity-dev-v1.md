# 名詞條件與主句肯否的四格對照

四句都問申請人依規定能否查閱會議資料。四句使用同一資格「外部委員」、同一動作「閲覧」及禮貌疑問句尾。問句中的當事人是申請人。原文沒有說明申請人實際具備哪種資格，也沒有回答查閱權限。

| 題號 | 條件 | 主句 |
| --- | --- | --- |
| NCP-01 | 是外部委員 | 問是否可以查閱 |
| NCP-02 | 是外部委員 | 問是否不能查閱 |
| NCP-03 | 不是外部委員 | 問是否可以查閱 |
| NCP-04 | 不是外部委員 | 問是否不能查閱 |

比較 NCP-01／03 及 NCP-02／04 時，只改條件中的「であれば／でなければ」。比較 NCP-01／02 及 NCP-03／04 時，只改主句中的「できますか／できませんか」。繁中譯文各自保留條件及主句的肯否。主句沿用條件中的申請人，並保留問句。

## 既有對照

L2-01／02 涵蓋事先分享資料的條件與讓步。N2-D03／04 涵蓋有漏填時的重填義務，以及即使沒有漏填仍須附上影本。兩組都同時改變了主句。資料檔以題號和 SHA-256 記錄來源。
