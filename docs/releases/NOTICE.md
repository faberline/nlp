# CPU CLI distribution notices

The `licenses` directory contains the exact notices tracked with the embedded multilingual lexicon and Mamba-derived code. The dictionary is compiled into the executable. Formal model weights are not included.

The English build script names Princeton WordNet 3.1. The tracked WordNet notice also identifies Open English WordNet 2023. [Open English WordNet's 3.1 release](https://github.com/globalwordnet/english-wordnet/releases/tag/3.1) describes a Princeton-derived edition. Its [current license](https://github.com/globalwordnet/english-wordnet/blob/main/LICENSE.md) also covers later Open English WordNet additions. These documents do not establish which input was used for this repository's English table. Keep the tracked notice intact and resolve the input identity before publication.

The package includes the dependency license files present in the locked Cargo metadata closure and a receipt listing its limits. Some upstream packages do not include a notice file in their crate archive. The precise WordNet input and some corpus and upstream notice details remain unverified. This notice does not assert that all distribution obligations have been established.
