# Invitation and negative-question examples

This development bank contains three original examples. All three use the polite ending `ませんか。`.

`INV-N5-01` invites someone to run together. `INV-N5-02` invites someone to drink tea together. The examples use different activities. They are complementary examples, not a minimal pair.

`INV-N5-03` asks whether this dog does not swim. Its reference keeps the negative meaning. The nonhuman subject and factual predicate do not suggest an invitation or request. Context can still affect how a negative question sounds.

The standing DEV examples give useful context. `jz150` invites someone to a movie and includes weekend time and a purpose stem. `jz148` uses `ましょう` for a shared walk. `jz149` uses `ましょうか` for a suggestion. `jz151` uses a negative form as a polite request and includes time and honorific language. These examples do not prove a universal meaning for `ませんか`.

The three new references are provisional. An independent reviewer should check the Japanese meaning and Taiwan wording before adoption. No runtime behavior is claimed here.
