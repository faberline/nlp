# N5 時間點與移動目標 に 對照 v1

## 題組

TPG-N5-01/02 使用相同的說話者和移動動詞「帰ります」。兩句都用肯定禮貌非過去式。TPG-N5-01 的「夕方に」表示回去的時間。TPG-N5-02 的「家に」表示回去的目標。每句只有一個「に」名詞組。

參考譯文分別寫作「我傍晚回去」和「我回家」。第一句不指定回去的地點。兩句都不指定這是習慣、安排或意圖。

## 既有對照

重用已採納的 HS-09、HS-03/04 和 CLOCK-C13。HS-09 在同一句中使用時間「夕方に」和目標「家に」。HS-03/04 的「店長に」表示電話對象。CLOCK-C13 的「教室に」表示移動目標。這些句子的日文和譯文不在本資料重複。
