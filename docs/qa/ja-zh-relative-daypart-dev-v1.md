# Relative day and daypart controls

This development bank has five rows with approximate N5 language. Each row describes the same reading event. The subject, action, object, location and sentence ending stay fixed.

`DAYPART-N5-01` places the reading in tomorrow afternoon. `DAYPART-N5-02` places it tomorrow without naming a daypart. `DAYPART-N5-03` places it in an afternoon but does not name the date. `DAYPART-N5-04` gives no time. `DAYPART-N5-05` places it tomorrow morning. The day and daypart modify the reading event. The source gives no numeric hour.

The references keep the same event. They do not add a weekday, clock time or date to rows that lack one.

The adopted `jz151` example also uses `明日の午後`, but it is a polite request. That speech act adds a confound. `jz160` uses `先週の会議`, where the temporal phrase modifies a noun inside the clause. It is not a sentence-initial time adjunct. `CLOCK-C03` has a numeric afternoon hour but no relative day. These are context anchors, not direct substitutes for the new five-row set.

The references are provisional. An independent reviewer should check the Japanese meaning and Taiwan wording before adoption. No runtime behavior is claimed here.
