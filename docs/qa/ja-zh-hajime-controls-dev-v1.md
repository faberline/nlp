# 始め and 初め controls

This development bank has four original examples with approximate N5 language. It does not certify a JLPT level.

`HAJIME-N5-01` states that a teacher starts a class. `HAJIME-N5-02` asks whether the teacher starts it. The two rows keep the same subject, direct object and verb. They differ only by final `か`.

`HAJIME-N5-03` uses `始め` as a noun in `本の始め`. It means the opening part of a book. `HAJIME-N5-04` uses `初めに` as a sequence adverbial. It means that the speaker writes a name first. The guide labels the phrase function. It does not assign a universal part of speech to either spelling.

The adopted `CB-B16` example uses `始めます` with an explicit noon time. The adopted `jz149` example uses `始めましょうか` for a suggestion. They give context for the verb but do not match the new statement and question pair.

These examples do not show runtime behavior. An independent reviewer should check the Japanese meaning and Taiwan wording before adoption. Do not run these new rows until adoption on verified main.
