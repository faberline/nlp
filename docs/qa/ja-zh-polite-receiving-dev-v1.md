# Polite receiving and ability controls

This development bank contains three contrast pairs. The examples use approximate N5 language. The level is not a certification.

`POLITE-N5-01` is a polite request to receive this material. `POLITE-N5-02` asks whether a stated distribution rule prevents nonparticipants from receiving the material. The source gives the eligibility context. This pair does not claim that every `いただけませんか` sentence is a request or an inability question.

`POLITE-N5-03` and `POLITE-N5-04` ask someone to hold or carry the same luggage. The positive and negative-form endings both make polite requests in this context. The negative form does not tell the listener to avoid carrying it.

`POLITE-N5-05` and `POLITE-N5-06` ask about the same dog's swimming ability. The shared context supports a literal ability reading. The negative reference keeps the negative proposition. Context may still affect how that question sounds.

The standing `jz116` example asks someone to take a photo for the speaker. It uses a te-form benefactive request. `jz151` asks for some of another person's time with a nominal receiving form. Its time and honorific wording add context. These examples are useful anchors, not runtime results for this bank.

The references are provisional. An independent reviewer should check the Japanese meaning and Taiwan wording before adoption. No translation or runtime behavior is claimed here.
