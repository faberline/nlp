# Volitional form controls

This development bank has four short examples. Each Japanese sentence begins with `みんなで歌い`. Each ends with the same Japanese period. The rows add no time or place.

`VOL-N5-01` states that the group sings together. `VOL-N5-02` proposes that the group sing. `VOL-N5-03` asks whether the group sings in a neutral activity-status context. `VOL-N5-04` asks about the proposal. The ordinary question can sound like an invitation in another context, so the bank does not claim a universal reading.

The Taiwan references use a statement, `吧`, an information question, and `好嗎`. These are natural examples. They are not the only valid forms.

The adopted `L5-01` is an ordinary polite statement with a daily time. `jz148` uses `ましょう` for a shared walk to a station. `jz149` uses `ましょうか` for a suggestion with `そろそろ`. `jz056` uses `ましょう` for meeting at a cafe near a station. They are context controls, not direct matches for this bank.

The four new Japanese lines are complementary forms for one activity. They are not four independent examples of every use. The references are provisional. An independent reviewer should check the Japanese meaning and Taiwan wording before adoption. No runtime behavior is claimed here.
