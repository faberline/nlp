# 返回時的時段與移動方式

這五個公開開發題使用第一方原創日文及台灣繁中參考，依 MIT 授權。RTM-01 與 RTM-02 檢查同一次返回的時段和移動方式。其餘三題保護持續時間、地點與設定值。級別是開發用的粗略分組。每題都附可接受的自然譯法。其他譯法若保留相同語意，可在逐句驗收時記錄。[資料提案](https://github.com/faberline/nlp/issues/245)

| 題號 | 逐句核對 |
| --- | --- |
| RTM-01 | 爸爸傍晚從車站回家。是走路回去，車站是起點，家是終點。 |
| RTM-02 | 妹妹在中午過後跑回學校的操場。時段屬於這次返程。 |
| RTM-03 | 妹妹在操場跑步，一直跑到中午過後。這句的「で」標示運動的地點。 |
| RTM-04 | 時鐘原本指向一點，指針被撥回中午十二點。調整指針的時間與操作人都未明示。 |
| RTM-05 | 廣播節目的時段從晚上改回傍晚。調整節目表的時間與操作人都未明示。 |

在原有的公開題中，TPG-N5-01/02 與 HS-09 可核對單動詞「帰る」的時間及目的地。L4-03/04 可核對步行到車站與從車站步行。N4X-02 可核對從車站到家的步行路線。各題沿用原 ID，資料檔記錄原檔的 SHA-256。[原始問題與 18 個診斷](https://github.com/faberline/nlp/issues/215#issuecomment-6995080874)

逐題沿用相同的 CPU 設定。目標語言是 `zh-Hant`，來源提示留空，詞表為空，模型目錄留空，beam size 為 1。每題均記錄完整設定。獨立審查者應檢查日文、各個台灣繁中參考及控制題的角色。公開採納後再用此題庫量測產品。[題庫與完整設定](../../crates/faberline-nlp-translate/tests/data/ja_zh/return_time_manner_dev_v1.json)
