## 請求和比對方式

每題依既有格式用 `jp` 儲存原文。這個欄名沿用日本語至繁中開發題庫的慣例。每筆 `fixture` 保存完整的重播設定。來源提示以 `fixture.translate_options.source_hint` 為準。`null` 時，CLI 省略 `--source-hint`。CLI 和函式入口都使用 `zh-Hant` 目標、空的術語表和預設翻譯選項。原文按 UTF-8 完整傳入。純 CPU 使用內建詞庫，模型目錄設定為 `null`。

SKH-01 至 SKH-03 原文、目標和其餘選項相同，只改來源提示。SKH-05 和 SKH-08 以同樣方式核對既有日文路徑。SKH-06 和 SKH-07 用相同的未知詞比較有無提示。「雲銅紋」是本案自造的詞。固定詞表查不到同形整詞。是否保留完整原文是這兩題的判定依據，語言標籤可沿用安全分流的結果。SKH-09 單獨核對日常台灣繁中的原文保全。

日文 CPU 路徑和中文同語系路徑都可能回傳 `track=variant_rule`。檢查者須核對實際翻譯使用的路徑、分句語言記錄及目標文字。無提示的題目另與修正前的行為比較。前後兩次使用同一份詞表。

## 詞義、量測與採納
