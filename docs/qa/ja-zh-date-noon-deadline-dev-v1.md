# 日曆日期與中午的截止對照

這十一道公開開發題使用第一方原創日文和台灣繁中參考，依 MIT 授權。每題提供一個主參考、兩個自然變體、必須保留的語意與原句未明示的資訊。[資料單 #250](https://github.com/faberline/nlp/issues/250)

| 評估組 | 截止題 | 語意保護題 |
| --- | --- | --- |
| 日曆日期 | DLC-01、DLC-03、DLC-05 | DLC-02 問單一日期，DLC-04 問實際星期幾，DLC-06 是具體時點，DLC-07 是五天長度 |
| 中午 | DLN-01 | DLN-02 是中午發生，DLN-03 是持續到中午，DLN-04 是較廣的白天 |

DLC-01／02 的「今月」讓「何日」指一個月中的幾號。DLC-03／04 的「来週」指定星期的範圍。DLC-05／06 以同一事件區分四月五日是最晚日期或實際日期。DLC-07 的「五日間」表示核對工作持續五天。固定日期的譯文保留已執行的動作。截止句保留截止當天也符合原句。

DLN-01 至 03 的第一句以十二點作為上午工作的結束時刻。這個語境讓第二句的「昼」指中午。相同的收拾桌面事件分別檢查完成期限、完成時點和活動持續的終點。DLN-03 只陳述活動持續到中午。DLN-04 用「日中」保留較廣的白天時段。

各題沿用純 CPU 的公開開發設定。目標語言為 `zh-Hant`，來源提示留空，詞表和模型目錄為空，beam size 為 1。既有日期／日數保護對照為 ND-01-CALENDAR-DATE 及 ND-02-DURATION-DAYS。TMD-N5-03／04 保護已核對的鐘點及已知星期截止。
