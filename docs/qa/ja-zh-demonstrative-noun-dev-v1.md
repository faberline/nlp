# N5 指示詞名詞與所有格對照 v1

## 範圍

資料作者撰寫了八句第一方 N5 開發題，以及臺灣繁體中文參考譯文和可接受變體。每筆都是 `development-visible`，且 `heldout` 為 `false`。

資料沿用已採納的 N5X-07/08。這兩筆以「この箱」對照形容詞肯定與否定。本組再測直接受詞中的指示名詞、獨立代詞，以及真正的名詞所有格 `名詞＋の＋名詞`。

## 題組

### その／あの 加名詞和受詞

DEM-N5-01/02 保留「我」作主詞，以及指示名詞作直接受詞。兩句對照肯定和否定。DEM-N5-01/03 保留主詞、書和肯定述語。兩句對照 `その` 和 `あの`。

在這兩句的語境中，臺灣繁體中文可用「那本書」翻譯兩者。完整的語篇和距離差異需要前文與空間情境。非過去式的習慣或意圖讀法也由情境決定。

### 獨立的 これ／それ／あれ

DEM-N5-04/05/06 保留「我的書」作述語，並替換獨立代詞。中文用「這」表示近指，用「那」表示非近指。`それ` 和 `あれ` 都可自然譯成「那」。這組涵蓋近指與非近指。進一步比較日文的三種指示距離需要情境。

### 指示詞和真正所有格 の

DEM-N5-07/08 保留「車」和白色述語。`この車` 指示車輛。`先生の車` 用名詞 `先生`、助詞 `の` 和名詞 `車` 表示所有或關聯。中文參考分別使用「這輛車」和「老師的車」。這組比較兩種指稱方式。車輛的身分由各句決定。
